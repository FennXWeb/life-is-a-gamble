# Life is a Gamble soundtrack

Place music files in the category folders below. The development and production build commands automatically regenerate `manifest.json`, and the game randomly selects a track from the active category.

- `menu/` — title screen and radio wake-up
- `ambient/` — outdoor exploration and the default fallback playlist
- `combat/` — turn-based combat
- `dialogue/` — NPC conversations
- `interior/` — building interiors

Supported file types: MP3, OGG, WAV, M4A, AAC, and FLAC. Multiple files may be placed in each folder, including nested subfolders. Tracks do not need special names.
